# Análise de Vendas Xbox Game Pass

## Objetivo
Este projeto tem como objetivo analisar uma base simulada de **mais de 3.500 registros de assinaturas do Xbox Game Pass**, utilizando **Excel** para responder perguntas de negócio e criar um **dashboard executivo**.

---

## Base de Dados
A base contém informações de assinantes, incluindo:
- ID e Nome
- Tipo de plano 
- Data de início
- Autorrenovação 
- Preço da assinatura
- Tipo de assinatura
- Season Pass
- Valor total consolidado

---

## Perguntas de Negócio
1. Qual o faturamento total de vendas de planos anuais?  
2. Qual o faturamento de planos anuais separados por auto-renovação e não auto-renovação?  
3. Qual o total de vendas de assinaturas do **EA Play Season Pass**?  
4. Qual o total de vendas de assinaturas do **Minecraft Season Pass**?  

---

## Resultados
- **Planos anuais com auto-renovação** geraram 7x mais receita do que os sem auto-renovação.  
- O plano **Ultimate** concentra praticamente todo o faturamento dos passes adicionais.  
- O **Minecraft Season Pass** teve maior adesão em planos Standard, enquanto o **EA Play** foi mais associado ao Ultimate.  

---

## Dashboard
O dashboard foi construído em Excel com:
- **Tabelas dinâmicas** para agregação de dados.  
- **Gráficos** para comparação entre planos e períodos.  
- **Indicadores de receita** por tipo de assinatura e passes adicionais.  

---
